- **Core**: React 19, Vite 7

- **Animations & Interaction**: GSAP, Framer Motion, Lenis Smooth Scroll, Spline 3D Runtime

## 🏃 Local Development

Navigate to the application folder and start the dev server:

```bash
cd priyanshu
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

To build for production:

```bash
npm run build
```
