# Priyanshu Kamal - Portfolio Application

This directory contains the front-end application built with React 19, Vite 7, and Tailwind CSS.

## Getting Started

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```

## Features

- Spline 3D background animation with center hero CTA
- Adaptive 3-column project showcase with glare hover interactions
- Interactive education & qualifications tree
- GitHub API integration with stargazer metrics
- Lenis smooth scroll combined with GSAP ScrollTrigger
